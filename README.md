# E-Commerce Draft

## Overview
A RESTful API project for managing products, categories, and users in an e-commerce system.

## Technologies
- ASP.NET Core Web API
- ADO.NET
- Stored Procedures
- SQL Server
- JWT Authentication

## Key Features
- Built APIs for product, category, and user management.
- Managed business logic & data validation via stored procedures and ADO.NET.
- Performed manual data mapping from SQL results to response models.
- Integrated JWT authentication to secure user access.
- Applied a layered architecture to enhance code maintainability.
